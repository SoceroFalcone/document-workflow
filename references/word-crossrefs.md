# Word 交叉引用

按 [任务范围判断](../SKILL.md#任务范围判断) 确定要交付的部分。新建的 DOCX 在其图表或数字文献引文属于本次范围时，建立可跳转、可更新的交叉引用。已有稿件在授权范围内转换或核查。只改字体、字号或间距时，保留已有引用域及其书签。先确认正文提及的对象和实际题注或文献条目对应，再建立链接。

## 编号和链接

- 图、表分别按在文中的顺序编号。题注按 [论文版式](paper-layout.md) 放置，保留题名间距。把「见图2」里的「图2」和「见表1」里的「表1」建立为可跳转的交叉引用。
- 数字文献引用链接到文末对应条目。为顺序编码制论文建立或整理引文时，按正文首次引用的先后自动重排文末条目，并同步更新正文和文末编号。重复引文共用原书签。同处引用多篇时按正文顺序处理。未在正文被引用的条目保留在末尾，沿用原相对顺序。任务、学校或期刊规定其他次序时采用指定次序。
- 采用顺序编码制的本科论文，正文文献标记如 [1] 置于相关内容右上角，方括号和编号一并用上标。位于句末时把标记放在句号前。现有引文位置按原义核对后调整。文末条目编号排在正常基线。
- Word 里的实现是用独立的序列域（SEQ）给图题、表题和文献条目编号，用书签保存目标身份，正文用带超链接的引用域（REF \h）。同一对象的多次引用指向同一目标。正文保留原有标点和数字引用的上标等格式。连续文献区间可展开为逐个可跳转的编号，确保重排时每篇文献的引用都保留。
- 现有 Word 题注、多级编号、分章图号，或由 Zotero 等工具管理的文献，沿用对应工具的引用方式。遇到同号多目标、无法辨识的图题、断开的书签或难以判定的引用范围，报告具体位置供确认。

## 新增、移动和删除

- 新增时把对象、题注和正文引用一起交给 Skill 建立域。给新增的手输编号一个当前未用的临时号，并用同一临时号标出正文引用。脚本会按条目的位置给出正式编号。移动时连同题注或文献条目及其中的域、书签一起移动。
- 在桌面 Word 中按 Ctrl+A、F9 更新域。若正文在题注或文献条目之前且仍显示旧号，再更新一次。如果表内个别引用未刷新，选中该表再按 F9。通常按住 Ctrl 单击正文里的图表编号或文献数字即可跳转。
- 删除目标时核查仍指向它的正文引用，按内容删除或改引。移动条目时按原书签继续引用。正文首引顺序再次变化时，重新调用首引排序。Word 的 F9 更新各字段的显示值，排序由 Skill 完成。

## 转换和核查

脚本适用于可直接识别的单层图表号和方括号数字引文。图表题注使用 Word「题注」样式，或可由正文中紧邻的图片、表格辨识。文献条目位于「参考文献」标题下，以 [1]、[2] 等开始。先做所需排版，再在副本上建立链接。按项目要求使用的其他编号体系用 Word 或对应的文献工具建立。

在有 Python 3.10+ 和 python-docx 的环境中，从 Skill 目录运行下列命令。check 核对新增的手输引用、书签、链接和编号结果。apply 另存为新文件，并重读核对生成结果。加 `--sort-bibliography` 检查或应用首引排序。对适用稿件同时用 `--superscript-citations` 设置和核对正文方括号数字引文的上标，保持编号域和跳转。本项只处理上标，句末位置按引用语义复核。它适用于正文后的单一数字编号文献表，按参考文献区之前的引用顺序计算。遇到同段内用换行隔开的编号条目时，拆成各自完整的 Word 段落。检查发现歧义时，先确认目标再转换。

~~~text
python scripts/word_crossrefs.py check "原稿.docx"
python scripts/word_crossrefs.py apply "原稿.docx" --out "原稿-交叉引用.docx"
python scripts/word_crossrefs.py check "原稿-交叉引用.docx"
~~~

按首引顺序另存并复查。

~~~text
python scripts/word_crossrefs.py apply "原稿-交叉引用.docx" --sort-bibliography --superscript-citations --out "原稿-文献首引排序.docx"
python scripts/word_crossrefs.py check "原稿-文献首引排序.docx" --sort-bibliography --superscript-citations
~~~

交付前抽查图、表和文献各一处的跳转。调整编号后检查实际显示与目标一致。
