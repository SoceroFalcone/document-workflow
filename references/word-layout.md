# Word 排版与校验

[默认配置](default-word.json)采用 A4 页面，上下 2.54 cm、左右 3.175 cm。中文用宋体（SimSun），西文用 Times New Roman，默认字色为黑色。文档标题为三号加粗居中，无下边框。一级标题为四号加粗，二级标题为小四加粗，三级标题为小四常规字重，正文为小四两端对齐。已有脚注正文用五号。用目标文档已有的标题样式辨识层级，或由用户指定角色。学位论文和学术论文的专用规则见 [论文版式](paper-layout.md)。

## 标题编号

按 [中文正文标题编号](../SKILL.md#中文正文标题编号) 核对实际显示的编号。使用 Word 多级列表时，由列表生成前缀，并核对同一标题只显示一组编号。交付前结合 Word 或渲染结果检查自动编号。

带图表和数字文献引文时，按 [Word 交叉引用](word-crossrefs.md) 建立或核查编号及跳转。已有的交叉引用域随正文保留。

## 段落

- 行距使用多倍行距 1.5，段前、段后均为 0 磅，关闭自动段距。新建文档用段落属性控制间距，避免插入空段撑开间距。
- 正文使用 Word 字符单位首行缩进 2 个字符。标题和脚注默认首行缩进为 0。正文对应 `w:firstLineChars="200"`，随字号以字符单位排版。
- 开启孤行控制。关闭「与下段同页」「段中不分页」「段前分页」「取消行号」「取消断字」。文本框紧密环绕为「无」。已有手动分页符、分节和空段属于源文档内容，应用脚本会保留。

## 应用和检查

在当前环境可运行 Python 3.10+ 和 `python-docx` 1.2 时，从技能目录运行以下命令。可用主机提供的 Python 解释器。文档和配置路径可以是绝对路径。

```text
python scripts/word_layout.py check "原稿.docx"
python scripts/word_layout.py apply "原稿.docx" --out "原稿-排版.docx"
python scripts/word_layout.py check "原稿-排版.docx"
```

- `--profile academic-paper` 应用学术论文的中文题名、一级和二级标题字体字号以及正文字号。
- `--profile thesis` 应用已映射的封面、摘要、关键词、目录标题、参考文献标题及条目的专用字号和字体，并提示印刷学位论文的 A4 和边距差异。脚本对已存在的段落应用版式。先按 [任务范围判断](../SKILL.md#任务范围判断) 确定要交付哪些部件。
- `--project` 可指定项目配置，`--template` 可传入从用户指定模板提取的排版配置，`--task` 可指定本次的覆盖配置。三者都是 JSON，且可以只包含要覆盖的字段，如 `{"paragraph":{"line_spacing_multiple":2.0}}`。按默认、论文版式、项目、模板、本次要求的顺序逐项合并。需要保留原有标题下边框时，可将 `roles.title.remove_bottom_border` 设为 `false`。
- `roles` 中的 `styles` 是匹配该角色的 Word 段落样式名。用它指定自定义样式。用 `roles.<角色>.east_asia_font` 和 `roles.<角色>.latin_font` 指定中文和西文字体。设为 `null` 时沿用对应通用字体。高优先级的通用字体设置可覆盖低优先级的角色字体。学位论文专用段落样式名见 [配置](thesis-word.json)，处理标题前先确认其实际角色。以直接加粗、编号或字号标记的标题需要人工识别，并在工作副本中映射到相应标题样式。
- 脚本适用于整套预设。用户限定只改一个属性或部分段落时，使用范围更窄的文档编辑操作，并复核指定属性。使用者可照本页在 Word 中手动设置；本次没有执行程序时，说明实际验证方式。
- 自动处理可识别的主文档段落和已有脚注正文，以及各节的页面尺寸和边距。报告会列出跳过的列表、表格、文本框、修订内容或无法辨识的样式。脚本把预设值写入现有段落和文字的格式属性，新增段落可再次运行检查。含横向或混合纸张尺寸的原稿，保留纸张和边距并提示复核。Word 文件可保留手工分页符，因此实际分页以渲染结果为准。
- 多级列表、自动目录、分节页码、图表及附录按 [论文版式](paper-layout.md) 在适用稿件中建立或核查。自动目录生成后核对各级及文后条目的字号和跳转。需要保留分节独立边距时，按对应节定向应用版式。正文数字引文可按 [Word 交叉引用](word-crossrefs.md) 应用上标并验证链接。
- `check` 只读，退出码 0 表示所检属性通过，1 表示发现差异，2 表示无法执行。`apply` 会重新打开生成的数据做同样的检查，再写入新的输出路径。报告以 JSON 输出，列出属性变化、规则来源和需复核项目。字号和间距通过 Word 文件属性校验，字体是否可用、实际换行和分页通过渲染检查。
