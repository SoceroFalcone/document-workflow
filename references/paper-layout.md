# 论文版式

先按 [任务范围判断](../SKILL.md#任务范围判断) 确定本次要交付的结构。普通写作或只处理正文时，应用字体、段落和标题规则。论文专用部件按明示的完整交付范围、单项要求或源稿已有结构处理。学位论文版式用于本科毕业论文、硕士论文、博士论文及用户指定按此体例处理的稿件。期刊或会议稿有独立要求时按目标规范处理。

## 纸型与页边距

- 两类论文的印刷版优先用 A4 纵向纸张（210 mm × 297 mm）。
- 印刷学位论文核对各节页边距，上、左各至少 25 mm，下、右各至少 20 mm。通用 Word 配置的上下 25.4 mm、左右 31.75 mm 已满足下限。需要独立设置封面边距、装订位置或镜像页边距时按任务或模板核对。

## 正文和标题

通用正文为中文小四宋体（12 磅）、西文及西文标点小四 Times New Roman。两端对齐，1.5 倍行距，段前段后默认各 0 磅，首行按 2 个中文字符缩进，开启孤行控制。用段落属性保持间距一致，西文在单词中间换行按版面与项目要求设置。

| 正文层级 | 默认编号 | 字体 |
| --- | --- | --- |
| 一级 | 一、 | 四号宋体，加粗 |
| 二级 | （一） | 小四号宋体，加粗 |
| 三级 | 1、 | 小四号宋体，常规字重 |

文档总题名独立于正文层级。按需要把正文三级映射到 Word 的「标题1」「标题2」「标题3」，在新建的结构化 Word 中用多级列表关联标题样式，使编号可随标题变动更新。选择对应层级的宋体、字号和字重作为编号字体，编号紧接标题。本预设从「一、」开始。项目明示章级结构时，另设章标题角色，参考小三号宋体加粗及项目编号规则。已有多级列表按授权范围调整并核对实际显示。

学术论文需要更紧凑的字号时，可选学术论文预设，中文总题名小二黑体、正文五号宋体、一级小四黑体、二级五号黑体。按要求优先级确定最终配置。

## 封面和摘要

下表用于适用本版式且本次应交付的部件。模板内的学校名、院系和作者等随目标稿件的实际信息填写。

| 部件 | 版式 |
| --- | --- |
| 论文编码 | 小四号楷体（12 磅），居右 |
| 封面抬头 | 学校名称和「本科生毕业论文（设计）」用一号宋体（26 磅）加粗居中 |
| 封面中文题名 | 小一号宋体（24 磅），加粗居中 |
| 封面英文题名 | 小一号 Times New Roman（24 磅），加粗居中 |
| 封面信息栏 | 院系、专业、年级、学号、指导教师、论文作者、完成日期。整组用三号宋体（16 磅）加粗居中 |
| 中文摘要 | 标题用「摘要」，小二号黑体（18 磅）加粗居中。正文用小四号宋体 |
| 中文关键词 | 「关键词」标签用四号黑体（14 磅），词条用小四号宋体 |
| 英文摘要 | 标题用 Abstract，小二号 Times New Roman 加粗居中。英文正文按小四号 Times New Roman |
| 英文关键词 | Key words 一行用小四号 Times New Roman |

原创性声明、使用授权说明按提交方明确要求和原稿范围处理。国际期刊等需其他前置结构时按其指定模板排版。

## 目录与分页

- 目录单独成页，通常放在摘要之后、正文之前。标题用二号黑体（22 磅）加粗，示例居中。用正文标题样式生成带页码、层级和跳转链接的 Word 自动目录。显示级别按任务要求，通常可选第 1 至 3 级。只改页码时更新页码，标题或层级变化时更新整个目录，再核对条目字体和链接。
- 默认正文编号对应目录条目，「一、」层四号宋体，「（一）」层小四宋体，「1、」层按小四宋体。指定章标题时，章目录条目小三号宋体加粗。单列的英文目录条目用四号 Times New Roman。结论、参考文献、致谢、附录在目录中用三号宋体加粗。用专用目录样式或更新目录后定向设置，保留页码和跳转。
- 简单换页用分页符。页眉页脚、页码、边距或纸张方向需要独立时用分节符，通常为下一页分节符。先解除该节的页眉或页脚与上一节的链接，再设置页码。
- 完整学位论文采用此预设时，按以下方式编排页码。封面无页眉和页码，中英文摘要不显示页码。目录独立用大写罗马数字（I、II、III…），正文用阿拉伯数字从 1 开始，文后部分通常续编。封面、致谢等在任务明确无需页码时，可在对应节用「首页不同」。Word 中用 PAGE 域、分节格式和起始页码实现，并在更新目录后核对实际页码。

## 图表、参考文献与附录

- 图题放在图下，表题放在表上，图和表各自使用自动题注顺序编号。编号至题名之间留一汉字宽。正文用可跳转的交叉引用。增删或移动图表后更新题注与正文引用。
- 跨页表重复实际表头，保持每行内容在同一页。按需要调整行高、字体、页边距和表格前后段距。学位论文表格优先用三线表，实际跨页时按适用要求检查续表标记。调整既有表格时核对合并单元格和数据。
- 文末「参考文献」标题用小二黑体加粗居中。文献条目用中文五号宋体、英文五号 Times New Roman（10.5 磅）。目录中的「参考文献」用本页的目录条目规格。按 [Word 交叉引用](word-crossrefs.md) 处理顺序编码、正文上标和跳转。
- 学位论文附录的编号和标题分别居中占一行，通常另起页。学术论文用「附录 A」「附录 B」依序编号。
